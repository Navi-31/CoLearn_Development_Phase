I put together a quick Python validation script using NumPy to check step-by-step orthogonality and Gram-Schmidt normalization on arbitrary finite matrices:

gram_schmidt_verifier.py
Python 3.11 · NumPy 
# Gram-Schmidt Orthonormalization
import numpy as np

def gram_schmidt(V):
    U = []
    for v in V:
        w = v - sum(np.dot(v, u) / np.dot(u, u) * u for u in U)
        if np.linalg.norm(w) > 1e-10:
            U.append(w / np.linalg.norm(w))
    return np.array(U)
