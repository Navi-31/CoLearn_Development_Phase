# CoLearn — Screenshots

This folder contains screenshots and demo images for the CoLearn README and documentation.

---

## How to Add Screenshots

1. Run CoLearn locally (`npm run backend`)
2. Open `http://localhost:3000` in your browser
3. Take screenshots of the key screens listed below
4. Save them in this folder using the naming conventions below
5. Update `README.md` to reference the images

---

## Suggested Screenshots

Use these filenames when capturing:

| Filename | Screen |
|----------|--------|
| `01-login.png` | Login page |
| `02-signup.png` | Signup with OTP step |
| `03-dashboard.png` | Suite dashboard (list of suites) |
| `04-workspace.png` | Active workspace with video tiles |
| `05-whiteboard.png` | Whiteboard in action |
| `06-drive.png` | Google Drive document panel |
| `07-private-chat.png` | Private messaging panel |
| `08-invite.png` | Invite modal with code and link |
| `09-screen-share.png` | Screen sharing active |
| `10-notifications.png` | Notification panel open |

---

## Recommended Screenshot Settings

- **Browser:** Chrome (latest), window width ≥ 1440px for best layout
- **Format:** PNG preferred; JPEG acceptable for large images
- **Resolution:** Retina/HiDPI if available (2x screenshots look better in README)
- **Privacy:** Ensure no real names, emails, or credentials are visible in screenshots

---
